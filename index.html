A Vitrine é um cliente web; os dados ficam no banco NoSQL atendido pelo serviço REST. Escolha o recurso da API Technoworks e informe os caminhos definidos na documentação.

Functions usa /api/items e os campos titulo, descricao e preco. REST e Easy usam RA; Easy usa somente GET, inclusive nas operações de escrita. A API deve aceitar CORS para a origem desta aplicação.
